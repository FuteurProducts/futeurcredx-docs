## 1. RESPONSE ENVELOPE (MANDATORY)

Every response MUST use this exact envelope:

```typescript
// Single entity
{
  "success": true,
  "data": T,
  "error": null,
  "meta": {
    "dataSources": ["experian", "prisma"],
    "lastUpdated": "2026-02-01T12:00:00Z"
  }
}

// List with pagination
{
  "success": true,
  "data": T[],
  "error": null,
  "meta": {
    "dataSources": ["prisma"],
    "lastUpdated": "2026-02-01T12:00:00Z"
  },
  "pagination": {
    "page": 1,
    "pageSize": 25,
    "total": 1250,
    "hasMore": true
  }
}

// Error
{
  "success": false,
  "data": null,
  "error": "Human-readable error message",
  "meta": null
}
```

**HTTP Status Codes the Dashboard handles:**
- `200` — Success
- `401` — Redirect to login
- `403` — Access denied display
- `404` — Resource not found
- `422` — Validation error (missing portfolioId, bad input)
- `429` — Rate limited (Dashboard reads `Retry-After` header)
- `500` — Generic error with retry
- `503` — Maintenance mode

## 2. AUTHENTICATION

**Current**: Dashboard uses Supabase Auth (to be switched to Clerk on Day 1)

**What the Dashboard sends:**
```
Authorization: Bearer <jwt_token>
Content-Type: application/json
```

**What the API must extract from JWT:**
- `userId` — The authenticated user
- `orgId` / `clerkOrgId` — The tenant/organization (for multi-tenant scoping)

**After Clerk migration, the Dashboard will send:**
```
Authorization: Bearer <clerk_jwt>
X-Clerk-Org-Id: <org_id>  (optional, may be in JWT claims)
```

## 3. PORTFOLIO SCOPING (MANDATORY)

**ALL `/dashboard/*` data endpoints require `?portfolioId=<uuid>`** as a query parameter.

If `portfolioId` is missing, return:
```json
{
  "success": false,
  "data": null,
  "error": "Portfolio ID is required. Pass ?portfolioId=<id>",
  "meta": null
}
```
HTTP Status: `422`

**Exception:** `/dashboard/portfolios`, `/dashboard/health`, and `/dashboard/api-keys/*` do NOT require portfolioId.

## 5. DASHBOARD BFF CLIENT CONFIGURATION

The Dashboard's HTTP client is at `src/services/bff/client.ts`. Currently configured:

```typescript
BASE_URL = `${import.meta.env.VITE_SUPABASE_URL}/functions/v1`
```

**On Day 2, this changes to:**
```typescript
BASE_URL = import.meta.env.VITE_API_URL  // e.g. "https://api.lumiqai.com"
```

All endpoints in this document should be prefixed with the API's base path. If the API uses `/api/v1`, then the Dashboard will call `/api/v1/dashboard/customers`, etc.

**Recommended**: API mounts all dashboard endpoints under `/dashboard/*` so the Dashboard BFF client can simply append the path.
